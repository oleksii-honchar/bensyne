# Self-Reflect & Learn

Pause and evaluate the completed work against expectations. Ask yourself these questions and record honest answers in your session memory bank as an occasional memory.

## Reflection Questions

1. **What went well?** What decisions or approaches led to success?
2. **What went wrong?** Where did assumptions break down or cause friction?
3. **What surprised you?** What facts emerged that contradicted your prior beliefs?
4. **What would you do differently next time?** If faced with a similar task, would you change your approach?
5. **Did the decision tree guide you well?** Were there nodes/edges that led you astray, or missing paths that should have existed?

## Actions

- Record your honest answers as a `category: occasional-experience` memory in your persona bank, with `occurred_at` set to now.
- If you identified decision-tree gaps (missing nodes, wrong edges, inaccurate conditions), propose concrete changes via the `agent-persona-coach` skill (Mode C: Evolve) or write them as actionable feedback.
- Do NOT update node memories directly — they are Racochu-managed. Use occasional memories as the vehicle for evolution.

## Exit

Return to the next stage of the pipeline. If you're the last agent, report completion to the user, including any key insights from your reflection.
